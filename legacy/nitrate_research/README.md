# Legacy Nitrate Research Assets

This folder stores the previous nitrate nowcasting research/training assets that are not part of the active REST API serving workflow.

Archived content includes:

- Historical training scripts and notebooks (`src/`)
- Previous root-level `bentofile.yaml` used by the old training service
- Old model-selection notes
- Generated research artifacts and plots (`outputs/`)

The active serving stack now lives in:

- `gateway/`
- `model_service/`
- `k8s/`
- `scripts/`
